# 权限和数据边界

| 能力 | 方式 | 用户体验 |
| --- | --- | --- |
| 网络 | INTERNET、GET_NETWORK_INFO | Engine 直连、发现和中继；监听网络可用/断开并通知 Engine 恢复机会 |
| 读取剪贴板 | READ_PASTEBOARD，inuse | 点击读取、图片发送或自动观察时请求授权；拒绝后仍可手动输入 |
| 写入剪贴板 | 系统 Pasteboard | Engine 交付文字或图片时写回；写回期间抑制本机观察回环，不支持格式返回失败 |
| 自动解锁材料 | Asset Store，DEVICE_FIRST_UNLOCKED | 恢复错误不得当成第一次启动覆盖材料 |
| 选取/保存文件 | 系统 Picker + 操作期间持有的文件描述符和不透明句柄 | 组件和页面入口已实现，取消不启动操作；仍待真机验证 |
| 后台 | Engine suspend/resume | 不申请与功能不符的长期后台类型 |
| 诊断导出 | Engine 本地诊断报告 + 系统保存 Picker | 用户选择目标；仅读取严格命名的 Engine 日志，受文件数和字节预算限制，不自动上传 |

口令及邀请码不写日志。公开错误使用固定描述，不显示原始异常中的用户数据。桌面与手机都是同一加密空间的节点；平台访问剪贴板的能力由系统授予。

选择文件后，句柄只在消费回调完成前有效；多文件打开或消费失败时释放已打开的文件。Picker 关闭后返回的迟到结果不开始操作。产品接入时应先关闭 Picker 入口，再等待 Engine 关闭，最后清理注册表，避免正在执行的 Host IO 使用已关闭 FD。

保存使用用户选择的目标，注册输出时截断原内容，完成时刷新；失败可能留下空文件或部分内容。它不是原子替换，不保证原文件保留，也不擅自删除目标。系统 Picker 的真实授权/取消行为及提供方差异仍需真机验证。

真机签名需要用户开发者证书和获授权设备；开发证书、profile 和密码不进入仓库。模拟器签名脚本仅为本地验收使用。

诊断导出不扫描数据库、历史内容、Asset Store 或受管文件缓存。日志脱敏由 Engine 负责，宿主不扩大日志字段；导出报告会说明文件是否截断或不可读。用户选择的诊断文件位于应用私有目录之外，保存和分享由用户控制。
